# Ansible — dual-cluster kubeadm + multi-primary Istio

Inventory is generated by Terraform (`discover-inventory.ps1`). Run from **WSL**.

Shared variables live in `inventory/group_vars/` (must sit next to the inventory files).

For full Windows host setup (Hyper-V, WSL, keys, Packer/Terraform), see the [root README](../README.md#requirements-one-time-host-setup).

## WSL packages (one-time)

```bash
sudo apt update && sudo apt install -y ansible genisoimage openssh-client openssl curl
```

`istioctl` is installed automatically by the Istio role into `~/.local/bin/istioctl` (pinned version in `inventory/group_vars/all.yml`).

When using `.\scripts\deploy-lab.ps1`, the Windows SSH private key is copied to `~/.ssh/id_ed25519_lab` for you. For manual runs:

```bash
mkdir -p ~/.ssh
cp /mnt/c/Users/<YOU>/.ssh/id_ed25519 ~/.ssh/id_ed25519_lab
chmod 600 ~/.ssh/id_ed25519_lab
```

OpenSSH rejects keys under `/mnt/c/...` because they look world-writable.

## Ping / site playbook

```bash
cd /mnt/d/automation/ansible
export ANSIBLE_CONFIG=/mnt/d/automation/ansible/ansible.cfg
export ANSIBLE_HOST_KEY_CHECKING=False

ansible -i inventory/dev.yml all -m ping
ansible-playbook -i inventory/dev.yml playbooks/site.yml
```

`ANSIBLE_CONFIG` avoids the “world writable directory” warning on `/mnt/d/...`.
